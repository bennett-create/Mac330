# Changelog

## Versioning

`MAJOR.MINOR.PATCH`

- **MAJOR** — bumped when the pack feels ready for a release.
- **MINOR** — bumped for each actual feature.
- **PATCH** — bumped for everything else (tweaks, fixes, small changes); just counts up.
